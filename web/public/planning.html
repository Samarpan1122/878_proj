Match your coordinates to a road

Up to 50 Nebraska-area coordinates. Each record needs a unique case_id and numeric lat/lng. Requests are not saved. Matching uses a conservative 20 m threshold and 6 m ambiguity margin; it differs from the historical screening pipeline.

Review record format

Each record requires case_id, proposed_segment_id, decision (correct, incorrect or unresolved), and reviewed_segment_id for resolved cases. Correct matches require identical IDs; incorrect matches require distinct IDs. Optional notes preserve review context.

[{"case_id":"your-review-case","proposed_segment_id":"original-road-id","reviewed_segment_id":"independently-reviewed-road-id","decision":"incorrect","notes":"Engineering review rationale"}]

Reviews are processed for this request and are not saved to an agency record system. Export the result to retain it. An analyst-selected sample is not automatically representative of the full network.

Required route format and input provenance

Each route needs route_id, source and an edges array. Each edge needs edge_id, segment_id from the screening dataset, length_miles, baseline_minutes, residential and allowed_vehicle_types. Unknown permissions can prevent ranking. Road connectivity is not verified.

[{"route_id":"your-route-id","source":"your verified routing source","edges":[{"edge_id":"your-edge-id","segment_id":"actual screening segment ID","length_miles":1,"baseline_minutes":2,"residential":false,"allowed_vehicle_types":["car"]}]}]

Numbers above illustrate the input format only. For observed traffic, add traffic: {travel_minutes, observed_at: ISO timestamp, source}. Optional edge restrictions: max_height_m, max_weight_tonnes. Optional congestion scenario: capacity_vph, baseline_flow_vph, additional_flow_vph. No network equilibrium or guaranteed congestion reduction is claimed.
